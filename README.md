# React Fundamentals - Interactive Learning Examples

A comprehensive collection of interactive React examples designed to teach fundamental concepts through hands-on learning. This repository provides progressive, well-structured examples that demonstrate core React patterns and best practices.

## 🎯 Purpose

This repository serves as an educational resource for learning React fundamentals through practical, interactive examples. Each component demonstrates specific React concepts with:

- **Progressive Complexity**: Starting with simple examples and building up to more advanced patterns
- **Interactive Learning**: Hands-on examples you can modify and experiment with
- **Real-world Patterns**: Practical implementations of common React patterns
- **Educational Content**: Detailed explanations, code structure examples, and best practices
- **Consistent Structure**: All examples follow the same educational format for easy learning

## 🚀 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd react-fundamentals

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:5173`

## 📚 Learning Path

The examples are organized in a logical learning progression:

### 1. **Props Example**

- Understanding component props and data flow
- Different prop types (string, number, boolean, array, function, children)
- Progressive complexity from simple to advanced prop patterns

### 2. **State Examples**

- Primitive state management (numbers, strings, booleans)
- Object state management with immutable updates
- Array state operations (add, remove, reorder)
- Complex state with multiple related states

### 3. **Counter**

- Basic useState hook usage
- State updates and calculations
- Multiple state variables
- State history tracking

### 4. **Toggle Theme**

- Dynamic styling based on state
- Multiple theme options
- Local storage persistence
- State-based UI changes

### 5. **Conditional Rendering**

- Different conditional rendering patterns
- Dynamic content display
- State-based UI logic

### 6. **Input Examples**

- Controlled components
- Form validation
- Real-time feedback
- Character counters

### 7. **Form Examples**

- Form handling patterns
- Validation strategies
- Complex form state management
- User interaction patterns

### 8. **useEffect Basics**

- Side effect management
- Dependency arrays
- Cleanup functions
- Data fetching patterns

### 9. **Todo App**

- List management
- CRUD operations
- State persistence
- User interaction patterns

### 10. **Users App**

- Complex data management
- Search and filtering
- Modal interactions
- Advanced state patterns
